# Bot Studio 插件

这个仓库提供 Bot Studio 的游戏试玩和头像材质。每个包都有独立的下载附件、版本与 SHA-256 校验值。

## 安装与卸载

在支持可选插件的 Bot Studio 中，打开「市场 → 游戏」或「皮肤工坊」。选择对应包并点下载，应用会验证后安装。已经保存文件时，可以使用「从文件安装」。卸载游戏会保留试玩记录。移除材质后，头像会显示基础形象并保留原有选择。
